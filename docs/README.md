# FerroLoop documentation

Public documentation for FerroLoop. Everything in this directory is published with the
repository; internal planning, owner rulings and the reasoning behind a decision live in the
private working notes instead (`notes/`, a gitignored symlink to the umbrella `Notes/` repo).

## Naming

Per [AGENTS.md](../AGENTS.md), anchor documents in this directory are `UPPERCASE`, single word
preferred (`ROADMAP.md`, `ARCHITECTURE.md`). Everything else is `lowercase-kebab-case.md`.
Never let case be the only difference between two paths, and reference files with their exact case.

## Contents

This directory is new and holds no anchor documents yet. `ARCHITECTURE.md` and `ROADMAP.md` are
the two expected first, and neither is written: the architecture and scope for the rebooted
project are still a draft in the private notes and are not ratified. Adding either one before
then would publish a design the owner has not approved.
